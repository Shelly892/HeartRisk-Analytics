# Heart Disease Risk Analytics System

**Hive + Hadoop + Docker + Data Visualization**

This project implements a cloud-based data analysis pipeline for heart disease prediction using Hadoop HDFS, Hive SQL, Docker containerization, and interactive web-based visualizations. The system processes 1,025 patient records through a distributed computing environment to generate demographic insights, risk stratification, and predictive analytics.

## Project Overview

### **Objectives:**

1. Deploy a distributed Hadoop/Hive cluster using Docker
2. Process medical datasets using Hive SQL transformations
3. Implement rule-based risk scoring algorithms
4. Generate demographic and clinical analytics
5. Create interactive web-based dashboards with Chart.js

### **Technologies Used:**

- **Big Data:** Apache Hadoop 3.2, Apache Hive 3.1
- **Containerization:** Docker, Docker Compose
- **Data Processing:** HiveQL, SQL
- **Visualization:** HTML5, CSS3, JavaScript, Chart.js, matplotlib
- **Languages:** Python, Bash scripting

### **Dataset:**

- **Source:** Heart Disease UCI Dataset (1,025 patients)
- **Features:** 14 clinical attributes including age, sex, blood pressure, cholesterol, ECG results
- **Target:** Binary heart disease classification (0 = No, 1 = Yes)

## Installation & Setup

### **Required Software**

- Docker
- Docker Compose
- Python 3.8+
- Jupyter Notebook
- pandas, matplotlib, seaborn
- A web browser
- VS Code with Live Server extension

### **Step 1: Start the Hadoop Cluster**

Navigate to the Docker directory and start all services:

```bash
cd docker-hadoop
docker-compose up -d
```

**Containers launched:**

- `namenode` — HDFS NameNode (master)
- `datanode` — HDFS DataNode (storage)
- `resourcemanager` — YARN resource manager
- `nodemanager` — YARN node manager
- `historyserver` — MapReduce job history server

**Note:** Hive is manually installed inside the `namenode` container, not running as a separate service.
**Verify all containers are running:**

```bash
docker ps
```

You should see 5 running containers.

### **Step 2: Install Hive in NameNode Container**

Since Hive is not included in the Docker Compose setup, we need to install it manually inside the namenode container.

#### **3.1 Copy Hive and raw data file to the namenode container:**

```bash
docker cp apache-hive-3.1.2-bin.tar.gz namenode:/opt/

docker cp /data/raw/heart.csv namenode:/tmp/
```

#### **3.2 Extract and configure Hive inside the container:**

```bash
# Enter the namenode container
docker exec -it namenode bash

# Extract Hive
cd /opt
tar -xzf apache-hive-3.1.2-bin.tar.gz
mv apache-hive-3.1.2-bin hive

# Set environment variables
echo 'export HIVE_HOME=/opt/hive' >> ~/.bashrc
echo 'export PATH=$PATH:$HIVE_HOME/bin' >> ~/.bashrc
source ~/.bashrc

# Create Hive directories in HDFS
hdfs dfs -mkdir -p /user/hive/warehouse
hdfs dfs -mkdir /tmp
hdfs dfs -chmod g+w /user/hive/warehouse
hdfs dfs -chmod g+w /tmp

# Initialize Hive metastore (Derby DB)
cd $HIVE_HOME
schematool -dbType derby -initSchema

# Verify installation
hive --version
```

#### **3.4 Test Hive is working:**

```bash
hive
```

You should see the `hive>` prompt. Test with:

```sql
SHOW DATABASES;
EXIT;
```

If you see `default` database, Hive is ready!

```bash
exit
```

## Execution Instructions

### **Phase 1: Data Upload to HDFS**

#### **1.1 Enter the NameNode container:**

```bash
docker exec -it namenode bash
```

#### **1.2 Create HDFS directory structure:**

```bash
hdfs dfs -mkdir -p /user/root/healthcare/heart
```

#### **1.3 Upload the dataset to HDFS:**

```bash
hdfs dfs -put /tmp/heart.csv /user/root/healthcare/heart/
```

#### **1.4 Verify the upload:**

```bash
hdfs dfs -ls /user/root/healthcare/heart
hdfs dfs -cat /user/root/healthcare/heart/heart.csv | head -5
```

---

### **Phase 2: Hive Data Processing**

#### **2.1 Launch Hive CLI:**

```bash
hive
```

#### **2.2 Execute Hive scripts in sequence:**

**Script 1: Create base tables**

```sql
SOURCE /hive_scripts/01_create_tables.sql;
```

This creates the `heart_raw` external table pointing to HDFS.

```sql
SELECT COUNT(*) FROM heart_raw;  -- Should return 1026
SELECT * FROM heart_raw LIMIT 5;
```

**Script 2: Apply risk scoring rules**

```sql
SOURCE /hive_scripts/02_scoring_rules.sql;
```

This creates the `heart_scored` table with:

- Age group classification (Under 40, 40-54, 55-64, 65+)
- Risk score calculation (0-5 points based on clinical factors)
- Risk level categorization (Low, Medium, High)

**Script 3: Generate aggregate statistics**

```sql
SOURCE /hive_scripts/03_aggregate_analysis.sql;
```

Creates summary tables:

- `age_group_stats` — Disease rates by age group
- `sex_stats` — Disease rates by gender
- `age_sex_stats` — Cross-tabulation of age and sex
- `risk_level_stats` — Patient distribution by risk level

**Script 4: Export results to CSV**

```sql
SOURCE /hive_scripts/04_export_results.sql;
```

Exports all summary tables to `/tmp/` directory inside the container.

#### **2.3 Verify table creation:**

```sql
SHOW TABLES;
```

Expected output:

```
heart_raw
heart_scored
age_group_stats
sex_stats
age_sex_stats
risk_level_stats
```

### **Risk Scoring Algorithm:**

The rule-based scoring system assigns 0-5 points based on:

| Risk Factor         | Condition   | Points |
| ------------------- | ----------- | ------ |
| Age                 | > 55 years  | +1     |
| Blood Pressure      | > 130 mmHg  | +1     |
| Cholesterol         | > 250 mg/dL | +1     |
| Fasting Blood Sugar | > 120 mg/dL | +1     |
| Exercise Angina     | Present     | +1     |

**Risk Level Classification:**

- **Low Risk:** 0-1 points (41.3% of patients)
- **Medium Risk:** 2-3 points (49.6% of patients)
- **High Risk:** 4-5 points (9.2% of patients)

## Key Findings

### **1. Age-Disease Paradox**

- Younger patients (Under 40) show 73.7% disease rate
- Rate decreases to 34.3% in 55-64 age group
- Contradicts typical age-disease progression patterns
- **Hypothesis:** Survivor bias or data collection limitations

### **2. Significant Gender Disparity**

- Female prevalence: 72.4%
- Male prevalence: 42.1%
- 30-percentage-point gap
- Females are 1.7× more likely to have disease in this dataset

### **3. Gender-Specific Age Patterns**

- **Females:** U-shaped curve (100% → 46.2% → 85.7%)
  - Young females: Highest risk (100%)
  - Middle-aged: Protective effect (46.2%)
  - Elderly: Risk rebounds (85.7%)
- **Males:** Linear decline (62.5% → 23.2%)
  - Steady decrease across all age groups

### **4. Risk Stratification**

- Low risk: 41.3% (423 patients)
- Medium risk: 49.6% (508 patients)
- High risk: 9.2% (94 patients)
- Most patients fall into medium-risk category
